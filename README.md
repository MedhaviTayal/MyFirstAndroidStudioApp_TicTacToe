# 🎮 Medhavi's Tic Tac Toe

My first official Android app! This game features a playful animated splash screen and three aesthetic, hand-picked color palettes.

### ✨ Features
- **Aesthetic UI:** Designed with deep purples, ocean blues, and forest greens.
- **Splash Screen:** A playful "Medhavi's First App" welcome animation.
- **Score Tracking:** Keep track of wins for Player X and Player O.

### 🚀 How to Install and Play
1. **Open this page** on your Android phone.
2. Click on the **Releases** section on the right side of this page.
3. Download the file.
4. Once downloaded, open the file.
5. Your phone might say "Blocked by Play Protect" or "Unknown App"—click **"Install Anyway"** (this is normal for apps not on the Play Store).
6. Start playing!
